MPI PJOK V3 — KASTILAB
Topik: Teknik lemparan bola kasti (melambung, mendatar, menggelinding)
Sasaran: Kelas VI / Fase C — SDN 9 Kodeoha — Tahun Ajaran 2026/2027

CARA MENJALANKAN LOKAL
1. Buka index.html menggunakan browser modern (Chrome, Edge, Firefox).
2. Aplikasi tidak memerlukan instalasi atau internet untuk fitur inti.

PUBLIKASI DI GITHUB PAGES
1. Buat atau buka repository GitHub Anda.
2. Pada halaman repository, pilih Add file > Upload files.
3. Unggah index.html dari folder ini, lalu klik Commit changes.
4. Buka Settings > Pages.
5. Di Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu klik Save.
7. Tunggu hingga tautan Pages muncul pada halaman Settings > Pages.

CATATAN
- Ini adalah aplikasi HTML mandiri. Jangan unggah ZIP sebagai pengganti index.html; unggah isi folder, terutama index.html ke root repository.
- Untuk mengganti aplikasi yang sudah ada: unggah file index.html baru dengan nama yang sama pada repository yang sama, lalu pilih Commit changes. GitHub akan menawarkan penggantian file lama.
- Hasil kuis dan interaksi hanya berlaku selama sesi browser, kecuali fitur yang secara eksplisit menyatakan lain.
- Pastikan hak akses repository dan kebijakan sekolah sesuai sebelum membagikan tautan publik.
